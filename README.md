# Linktree — Bigode Ensina

Página de links pessoais criada como exercício com React, Vite e Tailwind CSS.

**Projeto desenvolvido para fins educacionais.**

**Demonstração informada no repositório:** [linktree-bigode.vercel.app](https://linktree-bigode.vercel.app)

## Sobre o projeto

A interface mostra avatar, identificação e botões para canais sociais. É uma aplicação de uma página, sem backend ou persistência. Os botões são componentes React definidos em <code>src/components/Button.jsx</code>.

## Tecnologias

React 18, JavaScript, Vite e Tailwind CSS 3. Font Awesome é carregado na página para os ícones.

## Como executar

~~~bash
git clone https://github.com/Rafael-M-Silva/Linktree.git
cd Linktree
npm ci
npm run dev
~~~

Abra o endereço exibido pelo Vite, normalmente [http://localhost:5173](http://localhost:5173).

## Aprendizados e pendências

O projeto pratica componentes reutilizáveis, propriedades, estilos utilitários e links externos. O texto de apresentação em <code>src/App.jsx</code> ainda é um placeholder e o link do LinkedIn está sem protocolo; revisar esses pontos antes de usar a página como cartão profissional definitivo.
